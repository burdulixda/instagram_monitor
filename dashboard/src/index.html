      Session modes

      • No-login mode. No login required. Limited to basic profile info and post counts.
      • Logged-in mode. Requires an Instagram account login. Provides the full feature set, including follower and following lists, stories and detailed post and reel info.
      • Recommended. Use the Firefox cookie import for the best compatibility and lower detection risk.
      Do not use Instagram in the browser the session came from while the monitor is running. Simultaneous browser and tool activity can get the account flagged.
